# Villa do Farol — Site demonstrativo

Pousada boutique fictícia em São Francisco do Sul, SC. Portfólio comercial para prospectar clientes de hospedagem.

## Stack

- Vite + React + TypeScript
- CSS custom (design system areia / off-white / verde profundo / ouro)
- Reserva via WhatsApp (mensagem gerada no front-end)

## Rodar local

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```

## WhatsApp

Número placeholder em `src/data/content.ts` (`WHATSAPP_NUMBER`). Trocar pelo número real do cliente em produção.

## Nota

Marca, avaliações e contato são fictícios — conteúdo de demonstração.
